# مختصر روابط بـ PHP وSQLite مع إحصائيات

مختصر روابط خاص بك، بلا إطار عمل ولا Composer ولا قاعدة MySQL: ملفات PHP وقاعدة SQLite في ملف واحد، يعمل على أي استضافة مشتركة أو سيرفر.

شرح المشروع كاملاً، وكيف بُني واختُبر، على قيد: **https://qeeid.com/php-sqlite-url-shortener-project-source-code/**

## المزايا

- روابط قصيرة برمز عشوائي آمن (6 أحرف) أو باسم مخصص مثل `/offer2026`
- إحصائيات لكل رابط: النقرات، والزوار المختلفون، وآخر 30 يوماً، ومن أين جاؤوا، والجهاز، والمتصفح، وتنزيلها CSV
- المعاينة: أضف `+` بعد أي رابط قصير لترى وجهته قبل الذهاب
- إيقاف الرابط وتشغيله وحذفه
- لا تُحسب زيارات الزواحف ومعاينات الروابط في واتساب وتيليجرام
- لا نخزن عناوين IP: نخزن بصمة مموّهة بسرّ خاص بك
- واجهة عربية، ووضع ليلي تلقائي

## الحماية

- استعلامات محمية في كل مكان (Prepared statements)
- رمز CSRF في كل نموذج، وجلسة بملف تعريف `HttpOnly` و`SameSite=Lax`
- كلمات المرور بـ `password_hash`، وقفل 15 دقيقة بعد 5 محاولات خاطئة
- يقبل روابط `http` و`https` فقط، ويرفض `javascript:` والحلقات إلى المختصر نفسه
- رؤوس أمان: CSP و`X-Frame-Options` و`nosniff`
- صفحة الإعداد الأول تحتاج رمزاً من ملف الإعداد، وتُغلق نهائياً بعد إنشاء المدير
- فشل تسجيل النقرة لا يمنع التحويل أبداً

## المتطلبات

PHP 8.1 أو أحدث مع `pdo_sqlite` (موجودة في أغلب الاستضافات).

## التثبيت

1. ارفع الملفات.
   - **على سيرفر خاص (Nginx):** اجعل مجلد `public` جذر الموقع، وانظر `nginx.conf.example`.
   - **على استضافة مشتركة:** ارفع المجلد كاملاً إلى `public_html` (أو مجلد الدومين الفرعي). ملف `.htaccess` في الجذر يوجّه كل شيء إلى `public` ويمنع الوصول إلى `src` و`data` وملف الإعداد.
2. انسخ `config.sample.php` إلى `config.php`، وغيّر فيه:
   - `base_url`: رابط موقعك
   - `setup_token` و`secret`: نصان عشوائيان طويلان مختلفان
3. تأكد أن مجلد `data` قابل للكتابة.
4. افتح `/setup`، واكتب رمز الإعداد، وأنشئ حساب المدير.
5. من `/admin` اختصر أول رابط.

## الاختبارات

```bash
php tests/run.php
```

31 اختباراً تشغّل خادم PHP المدمج على قاعدة مؤقتة: الإعداد، وCSRF، ورفض الروابط الخطرة، والأسماء المحجوزة، وهروب HTML، والتحويل، وعدّ النقرات وتجاهل الزواحف، والمعاينة، وCSV، والإيقاف والحذف، وقفل الدخول.

## الهيكل

```
public/        جذر الموقع: index.php (كل المسارات) و assets
src/           bootstrap, schema, links, stats, auth, csrf
views/         قوالب الصفحات
data/          قاعدة SQLite (تُنشأ تلقائياً)
tests/run.php  اختبارات التكامل
```
